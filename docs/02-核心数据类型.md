# 02 · 核心数据类型

底层基础类型（L1）。目标：提供稳定、零开销的基础设施，供上层使用。**不引入除 glm 外的运行时依赖。**

## 1. 数学类型（glm 封装）

`include/anim/core/Math.h`

```cpp
#include <glm/glm.hpp>
#include <glm/gtc/quaternion.hpp>
#include <glm/gtc/matrix_transform.hpp>

namespace anim {
    using Vec2 = glm::vec2;
    using Vec3 = glm::vec3;
    using Vec4 = glm::vec4;
    using Quat = glm::quat;       // 注意 glm 构造顺序 (w,x,y,z)
    using Mat3 = glm::mat3;
    using Mat4 = glm::mat4;

    // Unity 用左手系；本库坐标约定由集成层统一决定（见 12），
    // 数学层只做纯代数，不硬编码手性。
}
```

约定：
- 四元数用 glm 默认存储；字符串/序列化时按 `(x,y,z,w)` 输出以对齐 Unity 的 `m_LocalRotation.x/y/z/w`。
- 单位四元数 `Quat(1,0,0,0)`。
- 度/弧度换算提供 `radians()/degrees()` 包装。

## 2. Transform（局部 TRS）

`include/anim/core/Transform.h`

```cpp
struct alignas(16) Transform {
    Vec3 translation{0};
    Quat rotation{1,0,0,0};
    Vec3 scale{1};

    Mat4 toMatrix() const;                 // T * R * S
    static Transform fromMatrix(const Mat4&);
    // 组合：父局部 * 子局部
    static Transform compose(const Transform& parent, const Transform& local);
};
```

`Transform` 与 mecanim `math::xform` 一样按 3 个 float4（t/q/s）布局：
`sizeof(Transform) == 48`、`offsetof(rotation) == 16`、`offsetof(scale) == 32`。
中间保留的 padding 仅用于 16 字节 SIMD 读写，不参与 TRS 语义。

原项目对应：Unity 的 `m_LocalPosition`/`m_LocalRotation`/`m_LocalScale`（见 `Examples/Art/Spider Bot/SpiderBot-MoveUp.anim` 的 `m_Local*` 通道）。

## 3. 对象池

`include/anim/core/Pool.h`

目的：避免热路径每帧分配（原项目大量使用 `ObjectPool`，见 `AnimancerLayer.cs:491` weightless 克隆、`AnimancerState.EventDispatcher.cs:108 Acquire`）。

```cpp
template <typename T>
class Pool {
public:
    T* acquire();            // 取一个（复用或新建）
    void release(T*);        // 归还并 reset
    void reserve(size_t n);
private:
    std::vector<std::unique_ptr<T>> _all;
    std::vector<T*> _free;
};
```

要求：
- `release` 后对象进入空闲栈；`acquire` 优先复用。
- 不要求线程安全；多线程场景由调用方分线程各持一个池（见 12）。

## 4. 序列化读写

`include/anim/core/Serialization.h`

用于 `.ab` 二进制（见 03）与黄金数据（见 13）。要求：
- 小端；显式版本号。
- 支持 `u8/u16/u32/u64/i32/f32/f64/bool/string/vec/quat`。
- 字符串用长度前缀（变长或 u32），带一张全局字符串表以减少重复。

```cpp
class Reader {
public:
    explicit Reader(std::span<const uint8_t>);
    uint32_t version() const;
    template <typename T> T read();
    std::string_view readString();
    bool eof() const;
};
class Writer {
public:
    void writeU32(uint32_t);
    template <typename T> void write(const T&);
    void writeString(std::string_view);
    std::vector<uint8_t> finish();
};
```

## 5. 字符串与哈希

`include/anim/core/Hash.h`

- `StringId`：对 bone 名、clip 名做 64-bit 哈希（FNV-1a），避免运行期大量 `std::string` 比较。
- 转换器会把字符串表和 `StringId` 一并写入 `.ab`；运行时按 id 查表。

```cpp
using StringId = uint64_t;
constexpr StringId hashString(std::string_view);
```

## 7. 关键不变量（务必在 debug 断言）

源自原项目语义：
1. 一个 Node 的 `Index >= 0` 才能连接到父（`AnimancerNode.cs:256`）。
2. State 的 `Root` 必须与其 `Parent` 的 `Root` 一致（`AnimancerNode.cs:421`）。
3. Mixer 的子节点索引必须从 0 连续（`ManualMixerState.cs:361`）。
4. `Weight` 必须为有限非负数（`AnimancerNode.cs:540`）。
5. `Speed` 必须有限（`AnimancerNode.cs:805`）。
6. `Time` 必须有限（`AnimancerState.cs:491`）。

## 8. 与 glm 的注意点

- glm 的 `quat` 乘法顺序：`q1 * q2` 表示先应用 `q2` 再应用 `q1`（与 Unity `Quaternion` 一致）。
- `glm::slerp` 在相邻关键帧之间插值旋转；混合器对多姿态用“累加+归一化”而非链式 slerp（见 04/08）。
- 欧拉角仅在转换器或工具需要使用；运行时一律用四元数。

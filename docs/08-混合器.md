# 08 · 混合器

L6 层的混合器：把多个子状态按权重合成一个 Pose。原项目：`Internal/Mixer States/*`。本库逐类移植，权重算法必须一致。

## 1. ManualMixerState（混合器基类）

原项目：`Internal/Mixer States/ManualMixerState.cs`。

```cpp
class ManualMixerState : public AnimancerState {
public:
    int childCount() const override;          // _ChildCount
    AnimancerState* getChild(int) const override;
    bool keepChildrenConnected() const override { return true; }

    void add(AnimancerState*);
    void add(ITransition&);
    void addRange(...);
    void remove(int index, bool destroy);
    void set(int index, AnimancerState*, bool destroyPrevious);

    void update(bool& needsMoreUpdates) override;   // base + 重算权重 + 同步时间
    bool weightsAreDirty() const; void setWeightsAreDirty(bool);
    bool recalculateWeights();                       // dirty 时调用 forceRecalculateWeights
    virtual void forceRecalculateWeights();          // 子类覆盖
    void normalizeWeights(float totalWeight);        // 除以 totalWeight
    void disableRemainingStates(int previousIndex);  // index 之后置 0
    static bool synchronizeNewChildren;              // 默认 true
    static float minimumSynchronizeChildrenWeight;   // 默认 0.01
};
```

关键点：
- `keepChildrenConnected` 恒为 **true**（`ManualMixerState.cs:45`）。子节点始终接在图里。
- 子节点索引必须连续从 0 开始（`ManualMixerState.cs:361`）。
- `update`（`:812-825`）：
  ```
  base.update()                       // 自身 fade/weight
  if (recalculateWeights()):
      for each child: child->applyWeight()   // 立即同步，避免子节点已先行更新导致不一致
  ApplySynchronizeChildren()          // 可选的时间同步
  ```
- `normalizeWeights(total)`（`:1319-1328`）：`if total==1 return; inv=1/total; 每个 child.Weight*=inv`。
- `disableRemainingStates(i)`（`:1306-1310`）：`i` 之后全部置 0。
- **时间同步**（`Synchronize`，`:919`）：让子动画相位一致（如走路/跑步切换）。仅当总权重 > `minimumSynchronizeChildrenWeight` 时生效（`:262,1171`）。

## 3. LinearMixerState（1D）

原项目：`Internal/Mixer States/LinearMixerState.cs`。`TParameter=float`，对应 Mecanim 1D Blend Tree。

`forceRecalculateWeights`（`:155-222`），精确算法：

```
weightsAreDirty = false
if childCount == 0: goto ResetExtrapolatedSpeed
i = 0; prevState = child(0); p = parameter; prevTh = threshold(0)
if p <= prevTh:
    disableRemainingStates(0)
    if prevTh >= 0: prevState.Weight = 1; goto ResetExtrapolatedSpeed
else:
    while (++i < childCount):
        nextState = child(i); nextTh = threshold(i)
        if p > prevTh && p <= nextTh:
            t = (p - prevTh) / (nextTh - prevTh)
            prevState.Weight = 1 - t
            nextState.Weight = t
            disableRemainingStates(i)
            goto ResetExtrapolatedSpeed
        else:
            prevState.Weight = 0
        prevState = nextState; prevTh = nextTh
prevState.Weight = 1
if extrapolateSpeed: playable.setSpeed(speed * (p / prevTh))
return
ResetExtrapolatedSpeed:
if extrapolateSpeed && valid: playable.setSpeed(speed)
```

- `extrapolateSpeed`（默认 true，`:32`）：参数超过最高阈值时按比例加速（`speed * p/lastThreshold`），实现“跑步更快”。
- `assertThresholdsSorted`：阈值必须严格升序无重复（`:120-147`）。
- `assignLinearThresholds(min,max)`：均匀分布（`:229-252`）。

## 4. DirectionalMixerState（2D 极坐标）

原项目：`Internal/Mixer States/DirectionalMixerState.cs`。`TParameter=Vec2`，对应 Mecanim 2D Freeform Directional。

预处理（`calculateBlendFactors`，`:144-209`）：对每对 `(i,j)`：
```
avgMag = (|th_i| + |th_j|)/2
diff   = |th_j| - |th_i|
angle  = signedAngle(th_i, th_j) * 2        // AngleFactor=2
polar  = Vec2(diff/avgMag, angle)
polar *= 1 / dot(polar,polar)
blendFactors[i][j] = polar
blendFactors[j][i] = -polar
```

权重（`forceRecalculateWeights`，`:76-140`）：
```
paramMag = |parameter|
for each i:
    diffIToP = paramMag - |th_i|
    angleIToP = signedAngle(th_i, parameter) * 2
    weight = 1
    for each j != i:
        avgMag = (|th_j| + |th_i|)/2
        polar = Vec2(diffIToP/avgMag, angleIToP)
        newWeight = 1 - dot(polar, blendFactors[i][j])
        weight = min(weight, newWeight)
    if weight < 0.01: weight = 0
    state.Weight = weight
    total += weight
normalizeWeights(total)
```
- `signedAngle(a,b)`：`atan2(ax*by-ay*bx, ax*bx+ay*by)`；任一为零向量返回 0（`:213-226`）。
- `childCount==1` 直接权重 1。

## 5. CartesianMixerState（2D 笛卡尔）

原项目：`Internal/Mixer States/CartesianMixerState.cs`。`TParameter=Vec2`，对应 Mecanim 2D Freeform Cartesian。

预处理（`calculateBlendFactors`，`:126-165`）：
```
for i in [0,childCount):
  for j in (i,childCount):
    d = th_j - th_i
    d /= dot(d,d)
    blendFactors[i][j] =  d
    blendFactors[j][i] = -d
```

权重（`forceRecalculateWeights`，`:70-122`）：
```
for each i:
    d = parameter - th_i
    weight = 1
    for each j != i:
        newWeight = 1 - dot(d, blendFactors[i][j])
        weight = min(weight, newWeight)
    if weight < 0.01: weight = 0
    state.Weight = weight; total += weight
normalizeWeights(total)
```

## 7. 与 L3 位姿混合的衔接

混合器只负责**算权重**（本层）；真正按权重合成 Pose 由 L5 的 `MixerNode`（L3 `blend`）完成：
- 每个子 State 的 `Weight` 作为 `MixerNode` 对应输入口的权重。
- `MixerNode::processFrame` 拉取各子 Pose，用 `skeleton::blend` 加权合成。
- 因此“权重正确性”可用黄金数据直接验证（不需要图）。

原项目：`Utilities/TimeSynchronizer.cs`、`TimeSynchronizationGroup.cs`。

### 11.1 与 Unity 实现的差异

1. **时间权威**：本库 `AnimancerState` 独占时间，`ClipNode` 关闭自动推进。
   因此同步子状态不是改 Playable 速度，而是改 `PlaybackSpeedScale`（等价倍率），
   由 State 推进时间时使用。这样 `ExtrapolateSpeed` 与同步可以叠加而不会互相覆盖。
2. **同步延迟**：Unity 在同一帧内先改 Playable 速度再让 Playables 推进；
   本库若子状态在混合器之前已被 pre-update 处理，则修正会在下一帧生效（相差 1 帧）。
3. **root 节点**：`AnimancerRootNode` 不进入 pre-update 列表，避免 swap-remove 打乱子状态顺序。
4. `MixerState` 的 `Hue`/`AppendParameter` 等仅用于 Inspector 的接口未移植。

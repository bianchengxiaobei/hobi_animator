# 04 · 骨架与位姿

L3 层：把“曲线采样结果”组织成可混合、可输出的**位姿（Pose）**，并定义骨架、混合、矩阵调色板、根运动提取。此层是本库对 Unity `Animator`/`AnimationStream` 黑盒的自建替代。

## 1. Skeleton

`include/anim/skeleton/Skeleton.h`

```cpp
struct Bone {
    StringId name;        // 哈希名
    int parent = -1;      // 父骨骼索引，根为 -1
    Transform restLocal;  // 绑定姿态/rest pose（T-Pose 或导入姿态）
    Mat4 inverseBind;     // 蒙皮用逆绑定矩阵（世界空间绑定姿态的逆）
};

class Skeleton {
public:
    std::vector<Bone> bones;
    int find(StringId) const;   // -1 表示不存在
    const Transform& restLocal(int i) const { return bones[i].restLocal; }
};
```

说明：
- `restLocal` 来自模型导入（你的引擎的模型资产），对应 Unity 的 Avatar 绑定姿态。
- `inverseBind` 仅用于渲染调色板；无蒙皮需求时可留单位矩阵。

## 2. Pose（位姿缓冲）

`include/anim/skeleton/Pose.h`

```cpp
struct Pose {
    std::vector<Transform> local;   // 与 Skeleton::bones 一一对应
    void resizeLike(const Skeleton& sk);
    void resetToRest(const Skeleton& sk);
};
```

- 这是 Unity `AnimationStream` 的等价物：每根骨骼一个局部 TRS。
- 所有节点求值最终都产出/写入 `Pose`。

## 3. 混合（Blend）

`include/anim/skeleton/Blend.h`

Animancer 的混合权重由混合器状态算好（08），传递给每个子状态；父层/混合节点按“权重加权累加 + 归一化”合成最终 Pose。

### 3.1 两两混合（用于线性插值场景）
```cpp
void lerpPose(Pose& dst, const Pose& a, const Pose& b, float t);
// translation/scale: lerp；rotation: glm::slerp（或 nlerp，见下）
```

### 3.2 加权累加（用于多路混合）
```cpp
void accumulatePose(Pose& acc,                          // 累加器
                    const Pose& src, float weight);     // 叠加 src*weight
void normalizePose(Pose& acc, const std::vector<float>& weights,
                   const Skeleton& sk);                 // 四元数归一化
```

推荐算法（与 Unity 混合语义一致的常用做法）：
- 平移/缩放：`acc.t += src.t * w`；最后不额外除总权重（由混合器保证总权重≈1，见 08）。
- 旋转：用“加权 nlerp 累加”然后归一化，或对权重最大者做参考的累加 quat（避免 slerp 链的奇点）。本库采用：
  ```
  Quat q = normalize( Σ w_i * sign(align(q_i, q_ref)) * q_i )
  ```
  其中 `q_ref` 取权重最大的子姿态，`sign` 保证半球一致（点积<0 时取反）。
- **参考实现**：Unity 的 mixer 采用加权平均后归一化；我们用黄金数据校验一致（13）。

> 注意：混合顺序与权重由 L5/L6（Mixer/Layer）决定，本层只提供原语。

## 4. 矩阵调色板（调色板输出）

`include/anim/skeleton/Palette.h`

```cpp
// skin matrices = worldPose(bone) * bone.inverseBind
void computePalette(const Skeleton& sk, const Pose& pose, std::vector<Mat4>& out);
```

- 先由 `local` 逐级相乘得到每骨世界矩阵；
- 再乘 `inverseBind` 得到蒙皮矩阵；
- 输出 `std::vector<Mat4>`，交给渲染层（bgfx）上传。

本层不包含任何渲染头文件（约束见 00）。

## 5. 根运动提取

`include/anim/skeleton/RootMotion.h`

Unity 的根运动来自 `Animator.deltaPosition/deltaRotation`（原项目 `RedirectRootMotionToTransform.cs:25`：`Target.position += Animator.deltaPosition; Target.rotation *= Animator.deltaRotation;`）。本库自建：

```cpp
struct RootMotionDelta {
    Vec3 deltaPosition;      // 本帧根位移（root space）
    Quat deltaRotation;
    bool hasMotion = false;
};

// 根据上一帧与当前帧 Hips 的全局变换差计算 delta（可选剥离水平/垂直分量）
RootMotionDelta extractRootMotion(const Pose& prev, const Pose& curr,
                                  const Skeleton& sk, int hipsIndex);
```

要点：
- 对通用骨骼：Hips 的局部平移/旋转变化即根运动；若模型根节点在骨层级顶层，取该根。
- 对人形：根运动来自 `RootT/RootQ`（Unity 语义，见 05）；提取时应在“肌肉→local”之后、或在 root 空间直接读取曲线。
- “应用”由 L6 的 `RootMotionRedirect*` 决定（重定向到某个变换或逻辑组件，见 10）。

## 6. 时间与循环

采样层不处理循环；由 `AnimancerState` 负责：
- `TimeD`（double）可持续增长；`Length>0` 时 `NormalizedTime = TimeD / Length`。
- 当 `IsLooping` 时，实际采样时间取 `wrap(TimeD, Length)`；否则钳制到 `[0,Length]`。
- 原项目语义见 `AnimancerState.cs:594 NormalizedTime`、`:627 MoveTime`。

## 7. 与 Unity 黑盒的映射

| Unity 引擎 | 本库 |
|-----------|------|
| `AnimationStream`（骨骼局部 TRS 流） | `Pose` |
| `AnimationClipPlayable` 采样并写入 stream | `sampleClip` -> `Pose` |
| `AnimationMixerPlayable` 加权混合 stream | `ManualMixerState` + `blend` |
| `Animator.deltaPosition/deltaRotation` | `extractRootMotion` |
| `Animator.BindStreamTransform` / 写回 Transform | `Skeleton::apply(pose)`（集成层） |

## 9. P1 实现备注（已完成）

已实现并通过测试（`tests/test_skeleton|blend|palette|rootmotion|sample_clip.cpp`）：

- **Skeleton**：`addBone` 强制拓扑序（`parent < index`）与名字唯一；`find` 走 `StringId` 哈希表。
- **Pose**：`resetToRest` 逐骨拷贝 `restLocal`；采样前必定重置，未出现的骨骼保持绑定姿态。
- **Blend**：
  - `normalizeWeights` 与 `ManualMixerState.NormalizeWeights`（`ManualMixerState.cs:1319`，`total == 1` 直接返回）一致。
  - 平移/缩放按 `acc += src * w` 累加；旋转用“权重最大者为参考 + 半球对齐 + 累加 + 归一化”，
    等价于加权 nlerp，避免 `q`/`-q` 抵消。
  - 权重强制有限且非负（对齐 `AnimancerNode.cs:540`）。
  - `Transform` 按 mecanim `xform` 的 3×float4 对齐；x86 上 `accumulatePose` /
    `normalizePose` / `resetAccumulator` 走 SSE2，单输入单位权重走拷贝快路径。
- **Palette**：对齐 `SkeletonPoseComputeGlobal` 的 `xformMul`：先做世界 TRS 组合，
  再 `palette[i] = worldTRS[i].toMatrix() * inverseBind`；`toMatrix` 直接对旋转矩阵
  列缩放并写平移列，避免逐骨 4x4 乘法。单骨查询支持 scratch 缓冲，避免逐骨分配。
- **RootMotion**：`extractRootMotion` 取根骨**世界空间**帧间差；旋转由 `Transform::fromMatrix`
  分解后再复合，避免缩放污染四元数。Unity 的 `Animator.deltaPosition` 语义在集成层按手性转换（12）。
- **sampleClip**：`BoneLocalClip` / `HumanoidClip` 均已实现；`HumanoidClip` 走
  `sampleHumanoidClip` 的 95 muscles + `RootT/RootQ` + 四个 goal 路径。
- **测试数据**：`tests/golden/spiderbot_data.h` 由脚本从
  `SpiderBot-MoveUp.anim` 的 `Root/RightUpperLeg` 旋转通道（9 个关键帧）生成，
  用于验证“四分量曲线 → 四元数 → Pose”链路；Unity 运行时 oracle 属于可选精确模式，
  默认以真实关键帧和 4.7 离线回归为准（见 [17](17-功能范围与验收.md)）。
